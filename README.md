# Roth GmbH — Onboarding-Formular

Responsives Einstellungsformular für Roth GmbH, gehostet auf Netlify mit Netlify Forms Integration.

## Features

- ✅ Vollständiges Personalfragebogen-Formular
- ✅ Responsive Mobile Design
- ✅ Netlify Forms Integration
- ✅ Validierung: Steuer-ID, IBAN, Versicherungsnummer
- ✅ File-Uploads (max. 8 MB pro Datei)
- ✅ Dankseite nach Absenden
- ✅ Deutsche Sprache

## Live

https://rothgmbh-einstellungsbogen.netlify.app

## Deployment

Deployed via Netlify mit GitHub-Integration.
